# anifind

A simple command-line tool for discovering anime and finding where to watch them.

## Features

- **Search Anime** :
  Search for anime by title and choose from the matching results.

- **Anime Details** :
  View useful information such as rating, number of episodes, status, air dates, genres and synopsis.

- **Streaming Platforms** :
  Check which streaming platforms are available for a selected anime.

- **Top Anime** :
  Browse anime based on top ratings, popularity and current trends.

- **Search History** :
  Keep track of the anime you have searched for and view your previous searches.

- **Caching** :
  API results are stored locally for a limited time, reducing unnecessary API requests when the same data is requested again.

- **Interactive Menus** :
  Navigate through the CLI using arrow keys instead of having to type menu numbers.
